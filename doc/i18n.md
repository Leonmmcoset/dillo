# User interface languages

Dillo and its bundled bookmark and download plugins support English and
Simplified Chinese. Language selection happens when each process starts.
Restart Dillo and any running plugins (`dpidc stop`) after changing your locale.

The first nonempty environment variable in this order selects the UI language:

1. `LC_ALL`
2. `LC_MESSAGES`
3. `LANG`

`zh_CN`, `zh_SG`, `zh_Hans`, `zh-Hans`, and bare `zh` select Simplified Chinese.
Encoding suffixes such as `.UTF-8` are accepted. English, `C`, `POSIX`,
Traditional Chinese, unrecognized languages, and an unset locale use English.
The browser still honors a requested Chinese locale when its system locale
data is unavailable. All translated text is UTF-8. Install a Chinese font
(for example, Noto Sans CJK) if characters appear as missing glyphs.
Dillo automatically selects an installed Chinese font for the default
sans-serif family; an explicit `font_sans_serif` setting in `dillorc` takes
precedence. The downloads window also selects an installed Chinese font.

For a single launch:

```sh
LC_ALL=zh_CN.UTF-8 dillo
LC_ALL=C dillo
```

With `LC_ALL` unset, `LC_MESSAGES=zh_CN.UTF-8 dillo` selects Chinese UI while
keeping the other locale categories unchanged. UI selection does not change
HTTP `Accept-Language`, website content, or numeric parsing. Website authors'
form labels and users' custom action names retain their original text. The
bundled user manual and technical parser diagnostics are currently English.

# Maintaining translations

The shared C interface is in `dlib/i18n.h`; both C and C++ callers use
`_("English source text")`. Messages without translations fall back to their
source text. Returned strings have static lifetime and must not be freed.

Add English/Chinese pairs to `dlib/i18n_zh_CN.h`, keeping entries in alphabetical
order for readability. Keep printf placeholders, their order, and literal `%%`
escapes identical. Do not translate URL schemes, HTML tag or attribute names,
configuration keys, or command identifiers. In HTML templates, translate the
visible text separately from the markup and keep the UTF-8 charset declaration.

Use `N_("English source text")` for constant initializers, then translate the
stored text with `_()` before displaying it. In particular, file-scope menu
templates must not translate before startup initializes the language. FLTK's
shared dialog and file chooser labels are initialized in `dw/fltki18n.hh`.

Catalogs are compiled into `libDlib.a`, so installed and uninstalled builds do
not require gettext, catalog compilation tools, or external catalog files.
Locale precedence and formatting tests run as part of `make check`.
